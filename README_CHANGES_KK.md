# TESTMAG жаңартуы

- Басты бетте атау/сипаттама бойынша нақты іздеу.
- Профильге логинді басып кіру; артық «Профиль» сілтемесі жоқ.
- Тест құру және өңдеуде 2–5 жауап нұсқасы: + қосу, − өшіру.
- Мұғалімнің өз нәтижелері «Менің нәтижелерім» бөлімінде; басқа мұғалімнің нәтижесі API арқылы да көрсетілмейді.
- Жаңа күлгін минималистік карточкалар және екі бөлек әрекет батырмасы.

## Орнату
1. backend қалтасында npm install, .env конфигурациясын өз серверіңізде орнатыңыз.
2. frontend қалтасында npm install және npm run build.
3. frontend/dist жинағын веб-хостингке орналастырыңыз, backend-ті Node.js серверінде іске қосыңыз.

Ескерту: Бұл жоба React/Vite + Node/MongoDB негізінде. InfinityFree-дің PHP/MySQL хостингі Node.js backend-ін тікелей іске қоса алмайды.
Қауіпсіздік үшін .env, құпия кілттер және бұрынғы жүктелген жеке құжаттар ZIP-ке енгізілмеді.
