TESTMAG жаңартуы

Қосылды:
1. Әр жауапты таңдағаннан кейін бірден Дұрыс/Қате көрсетіледі. Қате болса дұрыс жауап та көрсетіледі. Соңында жалпы нәтиже және жауаптар шығады.
2. Мұғалімге «Менің тесттерім»: өз тестін өту және түзету.
3. Тарихта іздеу және сұрыптау.
4. Кіру email емес, логин + құпиясөз арқылы.
5. Профиль: аты-жөні, логин, email, құпиясөзді өзгерту.
6. «Құпиясөзді ұмыттыңыз ба?» — email-ға уақытша құпиясөз жіберу.

Іске қосар алдында:
BACKEND: npm install
FRONTEND: npm install

Ескі аккаунттар үшін логин автоматты түрде email-дың @ белгісіне дейінгі бөлігіне тең болады.
Мысалы: 22B31023@qyzpu.edu.kz -> логин: 22b31023

Email жіберу жұмыс істеуі үшін backend/.env ішіне SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, SMTP_FROM қосыңыз.
Үлгі backend/.env.example ішінде бар.
